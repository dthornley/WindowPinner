New in 1.8: **WindowPinner updates itself.** The app checks GitHub for a newer release once a day and shortly after launch, and offers to download and install it. **Check for Updates…** in the menu does the same on demand; **Check for Updates Automatically** turns the daily check off. Updates are signed (EdDSA, verified by Sparkle) on top of the usual Developer ID signature and notarization.

This is the last release you need to install by hand.

## Install

**DMG (recommended):** download `WindowPinner-1.8.dmg`, open it, and drag WindowPinner into the Applications folder shown next to it.

**Zip (alternative):** download `WindowPinner-1.8.zip`, unzip it, and move `WindowPinner.app` to /Applications.

Then, either way:

1. Launch WindowPinner — a pin icon appears in the menu bar.
2. Grant **Accessibility** permission when prompted (System Settings → Privacy & Security → Accessibility). Required for reading and moving other apps' windows; without it the app can't do anything.
3. Click the menu bar pin icon and enable **Start at Login**.

Both downloads are Developer ID signed, notarized by Apple, and stapled — no Gatekeeper warnings, even offline.
